
# HR Analytics Dashboard

End-to-end HR analytics project — SQL business analysis + Power BI dashboard.

## Tools Used
MySQL Workbench, Power BI Desktop

## Project Overview
Analyzed HR dataset (1,480 employees) to uncover attrition drivers, 
compensation patterns, and department performance using SQL and 
built a 4-page interactive Power BI dashboard.

## SQL Analysis
Solved 50+ business requirements progressing from basic filtering 
through CASE statements, subqueries, correlated subqueries, window 
functions, and CTEs.

## Dashboard Pages
1. HR Overview — workforce composition and headcount
2. Attrition Analysis — attrition drivers by overtime, salary, tenure
3. Compensation & Performance — pay bands, top earners, work-life balance
4. Executive Summary — department-wise KPI rollup with CTE-based logic

## Key Insight
Research & Development has the lowest attrition rate (13.75%) and 
highest performance rating (3.16), making it the benchmark department 
for retention strategy.
